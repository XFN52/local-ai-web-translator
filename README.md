# Local AI Web Translator (Chinese to Russian)

Браузерное расширение (Manifest V3) для бесшовного и точного перевода веб-страниц с китайского на русский язык с использованием локального OpenAI-совместимого AI API (Ollama, vLLM, LM Studio, LocalAI и др.).

## Ключевые возможности

- **100% сохранение верстки и интерактивности**: работа исключительно на уровне `TextNode.nodeValue` и атрибутов без нарушения DOM-дерева и размонтирования React/Vue-компонентов.
- **Поддержка SPA и сложных UI-библиотек**: корректный перевод выпадающих списков (Semi UI Select / Popover), фильтров и динамических меню без зависаний и конфликтов наложения.
- **Перевод всплывающих подсказок и атрибутов**: перевод `data-tooltip`, `title`, `placeholder`, `aria-label` при наведении и рендере.
- **Экономия квоты модели (Viewport-only)**: первоочередный перевод только видимой области экрана, фоновый доперевод при скролле через `IntersectionObserver`.
- **Двухуровневый кэш переводов**:
  - Быстрый синхронный `pageCache` для повторяющихся строк без лишних IPC-вызовов.
  - Персистентный LRU-кэш до 5000 записей в фоновом воркере (`chrome.storage.local`).
  - Дедупликация идентичных строк внутри батча.
- **Авто-возобновление и устойчивость**: бесшовное продолжение перевода при переключении между вкладками (`visibilitychange`), истории маршрутизации (`pushState`/`popstate`) и повторных рендерах React.
- **Безопасный откат**: мгновенное и 100% точное восстановление оригинального китайского текста по клику на плавающий бейдж или кнопку в попапе.

## Установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/XFN52/local-ai-web-translator.git
   ```
2. Откройте страницу расширений в браузере (Chrome / Edge / Brave):
   `chrome://extensions/`
3. Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
4. Нажмите **«Загрузить распакованное»** (Load unpacked) и выберите папку проекта.

## Настройка

Нажмите на иконку расширения в панели браузера для вызова окна настроек:
- **API URL**: адрес эндпоинта чат-комплишенов (по умолчанию: `http://localhost:8045/v1/chat/completions`).
- **Модель**: название модели (по умолчанию: `gemini-3.8-flash-low`).
- **API Key**: Bearer-токен авторизации (при необходимости).
- **Размер батча**: количество строк в одном пакетном запросе (5–50).
- **Управление кэшем**: просмотр объема кэша и кнопка очистки.

## Тестирование

Запуск встроенного автономного набора тестов:
```bash
node test_dom_translation.js
```
